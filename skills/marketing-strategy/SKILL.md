---
name: marketing-strategy
description: "Propose what to set up in Leadhub next, based on the business results. Use when the user asks what to set up in Leadhub next."
---

Read `references/leadhub-capabilities.md`, `references/metrics.md`, and `references/segmentation-conditions.md`.

The goal is a plan: find where this business leaves revenue or growth on the table, and what in Leadhub would close it.

Start from what the business already has and how it is doing, with the tools the question needs. Without a range from the user, the last 90 days is a sensible default.

The examples of gaps in the capabilities reference are inspiration. Look for what this business needs, also when it is not listed there.

Rank the actions by expected impact. For each, say what to set up and where in the Leadhub web app, who it is for (rule JSON when a segment is involved), and how to tell whether it worked.

The user or the MCP write tools set the actions up in Leadhub as drafts, and nothing is launched or sent before the user confirms.

The files named above ship with this plugin, under `references/`. They are copies of the resources the Leadhub MCP server serves, so the skill does not need to read those resources.
